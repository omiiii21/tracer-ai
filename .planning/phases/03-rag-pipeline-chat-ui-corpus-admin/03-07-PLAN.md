<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local-dev client -> /admin/* | Unauthenticated (per ADR 009 / RESEARCH.md §5). v1 single-user local. |
| BackgroundTasks -> run_ingest | Background task captures per-job state; corpus mutation is the side-effect. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07-01 | Spoofing | /admin/* unauthenticated | accept | Documented as v1 single-user local-dev only (ADR 009). 4-line comment block at top of admin.py declares the boundary. Production hardening reserved for v1.5+. Compose db service exposes 5432 only on internal network; api is :8000 on localhost. |
| T-03-07-02 | Tampering | POST /admin/ingest {urls: ...} | mitigate | Per-URL regex validator from Plan 01 schemas (^https?://); error message format Line {N}: not a URL. Server-side Pydantic re-validates regardless of any client-side check. |
| T-03-07-03 | Denial of Service | concurrent ingest spam | mitigate | _active_job_id guard returns 409 on second concurrent POST; only one ingest at a time per RESEARCH.md §2. |
| T-03-07-04 | Denial of Service | URL list size | mitigate | Plan 01 schema caps urls list at 100 items. |
| T-03-07-05 | Tampering | PATCH /admin/chunking-config | mitigate | Plan 01 schema enforces chunk_size 100..4000 and overlap 0..500; chunker constructor (Plan 02) re-validates so even a bypass via direct module mutation cannot produce invalid Chunker instances. |
| T-03-07-06 | Repudiation | admin audit trail | mitigate | Every endpoint logs structured events (corpus_listed, ingest_dispatched, chunking_config_updated) via structlog. |
| T-03-07-07 | Information Disclosure | GET /admin/corpus surfaces full doc list + source URLs | accept | Local-dev only; the operator IS the user. Production deployment would gate this endpoint. |
| T-03-07-08 | Tampering | _jobs in-memory state | accept | Module-level dict is per-process; api restart wipes the job board. Documented as Phase 7 polish item to migrate to corpus_ingest_jobs DB table. |
| T-03-07-09 | Information Disclosure | error field in IngestStatus | mitigate | str(e) only — no traceback; full traceback to structlog. |
</threat_model>
